Weather App (Python Task 4)

A command-line Python application that fetches and displays current weather details for any city using the OpenWeatherMap API.

Features

Fetches real-time temperature (in Celsius), humidity, and weather conditions.

Validates user inputs and handles invalid city names or network errors cleanly.

Requirements

Python 3.x

requests library

Install the required library using:

pip install -r requirements.txt


How to Run

Get a free API key from OpenWeatherMap.

Run the script from your terminal:

python weather_app.py


Enter your API key and the city name when prompted.
