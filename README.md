Advanced BMI Calculator and Health Tracker

A desktop application built using Python, Tkinter, SQLite3, and Matplotlib. It calculates Body Mass Index (BMI), classifies health metrics based on WHO guidelines, stores historical entries per user, and visualizes progress trends over time.

Features

Clean GUI Interface: Built with form controls and color-coded result feedback.

Instant Calculation: Computes precise BMI scores using weight in kilograms and height in meters.

WHO Color-Coded Categories:

Underweight: Less than 18.5

Normal Weight: 18.5 to 24.9

Overweight: 25.0 to 29.9

Obese: 30.0 or greater

Data Persistence: Multi-user support with an embedded SQLite3 database (bmi_history.db).

Trend Visualization: Integrated line chart tracking historical BMI progress over time.

Input Validation: Handles empty fields, non-numeric entries, and invalid values gracefully.

Tech Stack and Dependencies

Language: Python 3.x

GUI Framework: tkinter

Database: sqlite3

Plotting Library: matplotlib

Installation

Install matplotlib using pip if it is not already installed:

pip install matplotlib


How to Run

Open your terminal or command prompt.

Navigate to the project folder:

cd OIBSIP/Python-Task2-BMICalculator


Run the application:

python bmi_calculator.py
